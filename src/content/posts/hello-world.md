오랜 고민 끝에 개인 블로그를 다시 시작한다. 이 글은 그 첫 번째 기록이다.

## 왜 블로그인가

플랫폼(네이버 블로그, SNS)에 글을 쓰면 편하지만, 글과 URL의 주인이 나가 아니게 된다. 이 블로그는 반대로 출발한다.

- 모든 글은 Markdown 파일로 내 컴퓨터와 GitHub에 남는다.
- 주소(`minseobkimmd.github.io`)와 수정 이력은 내 것이다.
- 언제든 개인 도메인으로 옮겨 붙일 수 있다.

## 다룰 주제

| 분류 | 내용 |
| --- | --- |
| Psychiatry | 정신의학, 정신약리학, 진료 현장에서의 생각 |
| Investing | 기업 가치평가, 경제 |
| Technology | AI, LLM, 에이전트 |
| Research | 정신측정, 연구 방법론, 연구 기록 |
| Essays | 짧은 에세이 |

주제가 섞여 보일 수 있지만, 기록이란 원래 그런 것이다. 태그와 검색으로 필요할 때 찾아보면 충분하다.

## 어떻게 만들었는가

Astro 정적 사이트 생성기와 [AstroPaper](https://github.com/satnaing/astro-paper) 테마, GitHub Pages 호스팅으로 구성했다. 서버 비용은 0원이고, `git push`를 하면 GitHub Actions가 자동으로 빌드·배포한다. 글쓰기 방법은 [글 작성 가이드](/posts/how-to-write-posts/)에 정리해 두었다.

## 앞으로

완벽한 글만 올리려다 보면 아무것도 쓰지 않게 된다. 생각의 초안을 공개하는 곳으로 쓰려고 한다. 꾸준함이 목표다.
